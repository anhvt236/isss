# ISSS – Định hướng du học

Website tĩnh giúp học sinh Việt Nam chọn trường, chọn ngành, xem cơ hội việc làm, so sánh chi phí, tìm học bổng, lập lộ trình và chuẩn bị hồ sơ du học Mỹ, Úc, Canada, Anh.

- Xem trực tiếp: https://anhvt236.github.io/isss/
- Chạy trên máy: mở `index.html` bằng trình duyệt, không cần cài đặt.

## Cấu trúc

| File | Nội dung |
|---|---|
| `index.html` | Khung trang |
| `css/style.css` | Giao diện |
| `js/app.js` | Các trang, bộ lọc, form tư vấn, đặt lịch, checklist, so sánh, chi phí, học bổng, lộ trình |
| `js/chatbot.js` | Trợ lý trả lời theo kịch bản |
| `js/faq.js`, `js/roadmap.js`, `js/resources.js` | Câu hỏi thường gặp, mốc lộ trình, nguồn tham khảo |
| `js/config.js` | Đường dẫn Google Apps Script nhận đăng ký và lịch hẹn |
| `data/data.js` | Dữ liệu quốc gia, trường, ngành, nghề, checklist |
| `google-sheets/` | Script ghi đăng ký vào Google Sheets và hướng dẫn cài đặt |

Số liệu cập nhật 11/2026 từ trang chính thức của trường và cơ quan nhà nước; luôn kiểm tra lại trước khi nộp hồ sơ.
